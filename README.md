## 谁该买 Pro，谁别买

值得买的几种情况。

外接 1080p 或 1440p 显示器，觉得字体发虚、边缘发糊，想要 HiDPI 缩放。这是 BetterDisplay 最核心的卖点，也是 139 元花得最值的地方。

显示器物理按键难按，想用键盘快捷键调亮度、切输入源。买之前先用免费版确认你的显示器支持。

多屏工作流，需要虚拟屏、镜像、画中画或者把画面串流到别的设备。

用 XDR/HDR 显示器，需要额外亮度和 SDR/HDR 自动切换色彩配置。

不用买的几种情况也说清楚。

只用 MacBook 内置屏，偶尔改改分辨率、调调亮度，免费版够了。

用 Studio Display 或 Pro Display XDR，系统自带的亮度、音量控制已经和 Mac 键盘打通，Pro 的额外功能你用不上。

Windows 用户，这软件只有 macOS 版。

只想调亮度对比度，不碰缩放。市面上有更便宜的单一功能显示器调节工具，BetterDisplay 的功能对你是过剩的。

算笔账。139 元买断，按用两年算，每天不到 0.2 元；用三年更低。和按月订阅的软件比，这是一次性支出，摊薄得很快。但更新只包一年，这一点下一节细说。

**发货后不退。** 购买须知第 3 条写得很直接，数字商品一旦交付就不支持退款，除非当地法律另有要求或另有售后政策。这不是商家苛刻，是数字商品的通例，但对你意味着：付款前必须自己验证兼容性。

**换机要反激活。** 在新设备上激活之前，得先在旧设备上把软件反激活。机器坏了开不了机的情况会比较麻烦。能激活几台 Mac，商品页没有写明具体数字，下单前确认一下。

**有系统和芯片门槛。** 部分功能需要 macOS Ventura 或更新版本，部分功能只在搭 Apple M 系列芯片的 Mac 上可用。Intel Mac 用户先看清楚自己机型支持哪些功能，别买完发现 HiDPI 用不了。

**独立评测不多。** 中文和英文的公开资料里，我没找到成规模的第三方评测或评分平台数据，能核对的只有官方功能表和商店的购买条款。看到把 BetterDisplay 夸得天花乱坠的稿子，先看它有没有给出具体机型、具体显示器的实测截图。
